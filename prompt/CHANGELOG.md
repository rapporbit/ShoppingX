# 提示词变更日志

版本号是 semver，文件在 `prompt/versions/<semver>.yml`。**正文只有一份**（`prompt/prompts.yml`），
版本文件是相对基线的叠加层（见 `1.0.0.yml` 头部注释与 `app/agent/prompts.py`）。

改提示词的两条路，别混：

- **改基线**（所有桶一起变）：直接改 `prompt/prompts.yml`，不发新版本号。适用于「明确的修正」
  ——错别字、指挥模型调不存在的工具、口径写反。这类改动没有可对照的假设，A/B 也测不出什么。
- **提假设**（只给一部分人）：新建 `prompt/versions/<新版本>.yml`，`base` 指向当前基线版本，
  `overrides` 里只写改动的键，然后在 `.env` 用 `PROMPT_AB_VARIANTS=<新版本>:10` 放 10% 的桶。
  攒够样本后跑 `scripts/eval/ab_report.py` 看达标与否，达标了再手工把百分比往上调（**不自动放量**）。

语义约定：主版本号留给「重写工作流骨架」，次版本号给「改某一段的策略」，修订号给「同一段里
措辞级的微调」。
